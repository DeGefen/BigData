# BigData

This repository hosts a Quartz-powered static website featuring my personal notes from the course **"Introduction to Big Data"** by Ran Silberman.

## 📚 About

- The site is built using [Quartz](https://github.com/jackyzha0/quartz), an open-source static site generator optimized for publishing Markdown-based knowledge bases.
- All notes reflect my understanding and learning progress in the course.

## 🚀 Getting Started (for local editing)

1. **Clone the repo:**
   ```bash
   git clone https://github.com/DeGefen/BigData.git
   cd BigData
   ```
2. **Install dependencies** (see Quartz documentation for setup instructions).
3. **Edit or add Markdown files** with your notes.
4. **Build and preview locally** as per Quartz instructions.

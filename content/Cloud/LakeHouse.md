>Data Warehouse as a service
- A modern data architecture that combines the best of two worlds:
	- **[[Data Lake]]s**: Flexible, scalable storage for all kinds of raw data (structured, semi-structured, unstructured).
	- **[[Data Lake#Data Lake vs Data Warehouse|Data Warehouses]]**: Fast, structured querying, optimized for analytics (using SQL, with strong schemas).
	
- Provide a **unified architecture** for both raw and structured data.
- Let you **analyze everything with SQL and machine learning**.
- Run **in the cloud**, so you don’t have to worry about servers or scalability.

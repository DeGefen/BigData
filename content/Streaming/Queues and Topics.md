### **Queue**
> A message delivery model where each message is consumed by only **one** consumer (used for **load balancing**).
> i.e., each message can be read by only one consumer.
![[Screenshot 2025-07-24 at 18.48.06.png|400]]

### **Topic**
> A message broadcasting model where each message is delivered to **all** subscribed consumers (used for **publish-subscribe** scenarios).
> i.e., each message can be read by multiple consumers.
![[Screenshot 2025-07-24 at 18.48.41.png|400]]
